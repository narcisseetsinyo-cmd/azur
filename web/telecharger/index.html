Choisis ton ordinateur

laptop_macSur Mac

  1. Pour savoir quel Mac tu as : menu Pomme › À propos de ce Mac. « Puce Apple » ou « M1, M2… » : choisis Mac Apple. « Processeur Intel » : choisis Mac Intel.
  2. Ouvre le fichier .dmg et glisse Azur dans Applications.
  3. Si macOS bloque le premier lancement : Réglages Système › Confidentialité et sécurité › Ouvrir quand même.

desktop_windowsSur Windows

  1. Ouvre le fichier Azur-Setup.exe téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires, puis Exécuter quand même.
  3. Connecte-toi avec ton compte Azur habituel : tes données arrivent toutes seules.
